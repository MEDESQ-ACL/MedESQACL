# Anonymous Repository Checklist

- [x] No author names in README, code, or metadata.
- [x] Original XLSX metadata not included; source rows are exported as CSV/JSONL.
- [x] No personal paths, emails, ORCID IDs, or institutional cluster names.
- [x] Model/API keys are read only from environment variables.
- [x] Paper draft is anonymous.
- [ ] Before upload, verify the Git remote URL does not reveal identity.
- [ ] If using an anonymous repository service, verify generated links do not expose the owner account.
